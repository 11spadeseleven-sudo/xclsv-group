# XCLSV Group Landing Page

React + Vite homepage concept positioned primarily around **Property Partnership**, with Property Maintenance and Project Management supporting the wider property proposition.

## Run locally

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite (usually http://localhost:5173).

## Main files

- `src/App.jsx` — homepage structure/content
- `src/styles.css` — complete visual styling and responsive behaviour
- `public/assets/` — XCLSV artwork supplied for the concept
